GALENBINDUNUWEWA API — Bilingual Tourism Website

Files: index.html, styles.css, script.js, assets/
Features: Sinhala/English toggle, responsive mobile menu, tourism-style teal/mint/sand background palette.
Photos/logo: cropped only from the Facebook screenshots supplied by the user; no outside stock photos added.

To preview: extract ZIP and open index.html in Firefox.
Optional local server: python3 -m http.server 8000, then open http://127.0.0.1:8000

The original Facebook post itself could not be fetched directly, so the available screenshot crops are used. Exact attraction names and travel directions should be verified before publishing. Static HTML/CSS/JavaScript; no database needed. Google Fonts need an internet connection.
